# Модуль конфігурування мережевих інтерфейсів та статичної маршрутизації

Розрахунково-графічна робота з дисципліни «Програмування на Python. Базовий рівень» (Варіант 18).
Спеціальність: F7 «Комп'ютерна інженерія».

## Стек
- Python 3.10+ (Miniconda)
- VS Code (`debugpy`, Pylance)
- Модулі стандартної бібліотеки: `sys`, `re`, `json`, `csv`, `time`

## Розгортання середовища
```bash
conda env create -f environment.yml
conda activate ce_rgr_env
```
