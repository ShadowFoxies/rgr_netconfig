## Реалізовані підсистеми

### 1. Валідація та нормалізація параметрів (`validators.py`)
Регулярні вирази (`re`), нормалізація рядків та 32-бітова арифметика IPv4 для перевірки адрес, неперервності масок підмереж, форматів MAC-адрес та ідентифікаторів VLAN (`1..4094`).

### 2. Об'єктно-орієнтована модель (`models.py`)
Ієрархія класів `NetworkEntity` → `NetworkInterface` → `VlanInterface` та `StaticRoute` з інкапсуляцією через `@property`, поліморфною генерацією команд `iproute2` та перевантаженням `dunder`-методів (`__str__`, `__repr__`, `__eq__`, `__lt__`, `__add__`, `__sub__`).

### 3. Відмовостійкість та маршрутизація (`exceptions.py`, `manager.py`)
Трирівнева ієрархія власних винятків (`NetConfigError`) для локалізації помилок валідації, дублікатів та недосяжних шлюзів (`UnreachableGatewayError`). Автоматична генерація bash-скриптів статичної маршрутизації.

### 4. Збереження стану та CLI (`storage.py`, `main.py`)
Персистентний експорт/імпорт у форматах `JSON` і `CSV` через менеджер контексту `with`, інтерфейс командного рядка на базі `sys.argv`, тестування `unittest` та бенчмаркінг через `time.perf_counter()`.

## Структура проєкту

```text
rgr_netconfig/
├── .vscode/
│   └── launch.json             # Конфігурація налагоджувача VS Code (debugpy)
├── data/
│   ├── sample_network.conf     # Штатна конфігурація інтерфейсів і маршрутів
│   ├── broken_network.conf     # Конфігурація для імітації аварійного стану
│   └── output/                 # Сформовані звіти (JSON, CSV, bash-скрипт, бенчмарк)
├── netconfig/
│   ├── __init__.py             # Публічний API пакета (__all__)
│   ├── exceptions.py           # Ієрархія користувацьких винятків
│   ├── validators.py           # Валідація мережевих параметрів (re, бітова арифметика)
│   ├── models.py               # ООП-ієрархія інтерфейсів та маршрутів
│   ├── manager.py              # Конфігуратор маршрутизації та парсер
│   └── storage.py              # Серіалізація JSON/CSV через менеджер контексту with
├── tests/
│   └── test_netconfig.py       # Модульні тести (unittest)
├── .gitignore                  # Виключення тимчасових файлів і кешу
├── environment.yml             # Специфікація середовища Miniconda
├── main.py                     # Точка входу та CLI-інтерфейс (sys.argv)
└── README.md                   # Опис проєкту та інструкція запуску
```

## Розгортання та запуск

```bash
# Створення та активація середовища
conda env create -f environment.yml
conda activate ce_rgr_env

# Штатний запуск із генерацією JSON, CSV та bash-скрипта
python main.py --input data/sample_network.conf

# Імітація аварійної ситуації (перехоплення винятку)
python main.py --input data/broken_network.conf

# Бенчмаркінг швидкодії
python main.py --benchmark

# Запуск модульних тестів
python -m unittest discover -s tests -v
```
